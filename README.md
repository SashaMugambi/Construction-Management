Construction Management ML

A machine learning MVP exploring how construction project data can support planning and decision-making for architects and engineers.

The project analyses construction parameters including built area, module price, construction duration, project delays and productive construction time. Machine learning models are explored to identify patterns and support estimation of key construction planning parameters.
Features
. Construction data analysis and preprocessing
. Exploratory data analysis
. Feature engineering
. Construction duration and built-area prediction
. Decision Tree modelling
. Model evaluation and prediction

Technologies
Python · Pandas · NumPy · Scikit-learn · Jupyter Notebook · Machine Learning

Project status: MVP / exploratory machine learning project.
